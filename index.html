Add community mods to your own copy of the official Sealegs 1.3.5.0 firmware.

🔒 Runs entirely in your browser. Your firmware is never uploaded, and this site hosts none.

1Load your official firmware

Use the unmodified Sealegs.1.3.5.0.bin from the manufacturer. Other versions are refused, because every patch targets exact addresses.

2Choose your mods

Mods can be mixed freely, with one rule: Live reverse needs Digi doppler, so picking reverse turns doppler on. Reverse, character and doppler share one engine, which is added once.

3Build and download

Generates a modified image the same size as the original. Install it with the same update procedure you use for official firmware.

Keep your original Sealegs.1.3.5.0.bin. To go back to stock, flash it again with the official update procedure.

How it works

The page holds only the added code and a handful of changed constants: no part of the official firmware is included. After your file passes the version check, the patches are written into a copy in memory. The result is then checked against the expected SHA-256 for your exact mod combination.

The patches were verified in an ARM Cortex-M7 emulator running the firmware's own DSP code. Reverse, character and the stability fixes were also tested on hardware. Newer combinations (reverse without character, character or doppler on their own, character with stock Digi) have so far only been verified in emulation.
